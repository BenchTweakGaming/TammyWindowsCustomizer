INTRODUCTION
------------
Please read this document to understand how to use this program.

This is a reused software. The latest Wrapper from Sophia Script for Windows was reused to make
a standalone customizer.

Named after a friend. Comes with a light 'Pink' theme that Tammy likes.

When you launch the software the Sophia Preset is loaded so you can use this preset to customize
right away.

Import your own preset and export for sharing.
